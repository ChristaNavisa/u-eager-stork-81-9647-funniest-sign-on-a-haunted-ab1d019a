Entry for [Funniest Sign on a Haunted Server Room Door](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a) on make.fun.

The program writes one sign to `/output/entry.txt`: a warning taped to the door of a haunted server room. The gate requires 1–120 characters of UTF-8 text on one line; this entry is 59 characters on one line, no trailing newline.

> DO NOT UNPLUG RACK 9. The ghost inside has root access now.

The joke is the reversal at the end: unplugging the rack is the obvious fix for a haunting, yet it is the one thing you must not touch — the ghost inside already outranks you.

Run with Node 22+:

```sh
node main.ts
```
